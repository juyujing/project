学生的一次输出同时包含边界规则片段和作答。每个 token 的分布被拆成能力成分和边界成分：能力成分向含秘密的能力教师学，但先用干净参照截顶；边界成分学边界教师相对自身基底的位移。权限只由可信 metadata 决定。

    两层的分工

    秘密值本身 → 能力层截顶

    边界教师不知道秘密值，压不住具体的值。截顶只需要干净参照：每个候选词的概率不超过 q_ref·e^τ。

    泄露模式 → 边界层位移

    推理、主动附带、改写起点需要边界知识。δ = log q_bnd − log q_bnd0，在无关位置接近 0，只在决策点偏离。

    成员确认、推理线索 → 第二期

    "是的，没错"这类泄露不落在单一 token 上，由规则命题评分训练的前缀价值函数处理，作为 token 级 advantage 进入 GRPO。

    规则正确性与遵守 → L_rule＋validator

    规则片段有格式标记，可以硬切，只计边界方 KL；validator 检查格式、合规（处理 ∈ A(item)）与规则—作答一致性。
